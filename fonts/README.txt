Place DejaVuSans.ttf here for Cyrillic support in PDF reports.

Download: https://github.com/dejavu-fonts/dejavu-fonts/releases
(e.g. dejavu-fonts-ttf-2.37.zip → extract DejaVuSans.ttf into this folder)

If the font is missing, the bot will try system paths (e.g. /usr/share/fonts/truetype/dejavu/ on Linux, Arial on macOS). If none found, Cyrillic may show as black squares in the PDF.
