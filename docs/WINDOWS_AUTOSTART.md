# Запуск eLibroBot на Windows: автостарт после перезагрузки

Цель: бот работает **сам по себе** (без IDE), **поднимается снова после каждой перезагрузки** Windows.

## 1. Подготовка на ПК

1. Установите **Python ≥ 3.9** (с галкой *Add Python to PATH*, если ставите с python.org).
2. Склонируйте/скопируйте проект, например в `C:\apps\eLibroBot`.
3. В каталоге проекта:

   ```bat
   cd C:\apps\eLibroBot
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```

4. Создайте файл **`.env`** (из `.env.example`) и заполните токен и чаты — иначе бот не стартует.

5. Один раз проверьте руками:

   ```bat
   cd C:\apps\eLibroBot
   .venv\Scripts\python.exe main.py
   ```

## 2. Скрипт для планировщика

В репозитории есть **[`scripts/windows/run_bot.bat`](../scripts/windows/run_bot.bat)**:

- переходит в **корень** проекта;
- использует **`.venv\Scripts\python.exe`**, если есть, иначе `venv\Scripts\python.exe`, иначе `python` из PATH;
- пишет вывод в **`logs\bot.log`** (каталог создаётся автоматически).

Путь к батнику после клонирования в `C:\apps\eLibroBot` будет:

`C:\apps\eLibroBot\scripts\windows\run_bot.bat`

## 3. Ручной запуск (когда нужно запустить самому)

Используйте любой из вариантов — бот должен быть в сети, пока открыто окно/процесс.

**Вариант A — через Python (удобно смотреть лог в консоли):**

```bat
cd C:\apps\eLibroBot
.venv\Scripts\python.exe main.py
```

**Вариант B — двойной щелчок по `run_bot.bat`** (или запуск из cmd):

- лог пишется в **`logs\bot.log`**;
- окно **cmd** остаётся открытым на время работы бота.

**Вариант C — уже настроен планировщик:**

- **Планировщик заданий** → задача `eLibroBot` → **Выполнить** (то же, что при проверке в п. 5 ниже).

**Важно:** не запускайте **два экземпляра** одновременно (два окна с `main.py` или задача + ручной запуск) — будет конфликт long polling у Telegram.

## 4. Планировщик заданий (рекомендуется)

Откройте **Планировщик заданий** (`taskschd.msc`) → **Создать задачу…** (не «простую» — нужны все вкладки).

### Вкладка «Общие»

- **Имя:** например `eLibroBot`.
- Отметьте **Выполнять для всех пользователей** только если нужен запуск до входа (тогда понадобятся права и настройка учётной записи задачи).
- Для домашнего ПК обычно достаточно **только для вашей учётной записи**.
- Установите **Выполнять независимо от входа пользователя** *или* **только при входе в систему**:
  - **При входе** — проще: сеть и профиль уже доступны, меньше сюрпризов с `.env`.
- Отметьте **Выполнять с наивысшими правами** только если без этого не видит сети/файлов (часто не нужно).

### Вкладка «Триггеры»

**Только запуск при загрузке / входе в систему** (без расписания «ежедневно» и т.п.):

- **Создать** → **При входе в систему** (или **При запуске компьютера**).
- При необходимости задайте **Отложить задачу на:** 30 секунд — чтобы успел подняться Wi‑Fi/VPN.

Другие триггеры (по расписанию) для этой задачи **не добавляйте** — иначе можно получить второй запуск бота, пока первый процесс ещё работает.

### Вкладка «Действия»

- **Создать** → **Запуск программы**.
- **Программа или сценарий:** полный путь к `run_bot.bat`, например  
  `C:\apps\eLibroBot\scripts\windows\run_bot.bat`
- **Рабочая папка:** корень проекта, например  
  `C:\apps\eLibroBot`  
  (батник сам делает `cd`, но указание папки не мешает.)

### Вкладка «Условия»

- При ноутбуке: при необходимости снимите **Запускать только при питании от электросети**.

### Вкладка «Параметры»

- **При сбое выполнения перезапускать через:** 1 минуту, **количество попыток** 3–10 — чтобы бот поднимался после падения.

Нажмите **ОК**, введите пароль учётной записи, если планировщик попросит.

## 5. Проверка

1. Запустите задачу вручную: библиотека планировщика → ваша задача → **Выполнить**.
2. Откройте `logs\bot.log` — должны быть строки запуска и логи Python/aiogram.
3. Перезагрузите ПК и убедитесь, что бот снова в сети.

## 6. Частые проблемы

| Симптом | Что проверить |
|--------|----------------|
| Задача не стартует | Путь к `run_bot.bat`, наличие `.venv`, `pip install`, рабочий `.env`. |
| Сразу выходит | Смотреть конец `logs\bot.log`, ошибки токена/сети. |
| Нет интернета при старте | Триггер «При входе» + **задержка 30–60 с** или автозапуск VPN. |
| Окно CMD мелькает | Это нормально для `.bat`; для полного скрытия можно в задаче указать `pythonw.exe` и отдельный лог — по необходимости доработаем. |

## 7. Запуск без Python: один `.exe` и ярлык

Если на целевой машине **нельзя ставить Python**, а нужен **один исполняемый файл и ярлык**, используйте сборку **PyInstaller** (в репозитории уже есть spec и скрипт сборки).

Пошагово: **[`WINDOWS_EXE_DEPLOY.md`](WINDOWS_EXE_DEPLOY.md)** — сборка на ПК с Python, перенос `eLibroBot.exe` + `.env` в одну папку, ярлык и планировщик.

**Важно:** рядом с exe всё равно кладут **`.env`** (токен и чаты не вшиваются в exe). Это один каталог развёртывания и один ярлык на программу.

**Минусы exe по сравнению с `run_bot.bat`:** больший размер, пересборка после обновлений, возможные ложные срабатывания антивируса — для ПК **с установленным Python** проще оставаться на **§2–§4** этого документа.

## 8. Альтернатива: папка «Автозагрузка»

Менее надёжно, чем планировщик (нет перезапуска при сбое). Ярлык на `run_bot.bat` в:

`shell:startup`

Подходит только если вы **всегда** входите в ту же учётную запись.
