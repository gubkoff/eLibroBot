# Визуальный baseline PDF (план V3, шаг 002)

## Как воспроизвести

```bash
. venv_int/bin/activate   # или ваш venv
python scripts/generate_pdf_baselines.py
```

Файлы:

| Файл | Назначение |
|------|------------|
| `docs/baseline_pdf_short.pdf` | **Короткий контент** — компактная накладная (мало текста в грузе). |
| `docs/baseline_pdf_long.pdf` | **Длиннее** — удлинённое поле «Товар» (повтор блока слов), чтобы сработал fallback «две страницы». |

## Ожидаемое поведение (на момент фиксации)

### `baseline_pdf_short.pdf`

- Одна страница A4.
- Два полных экземпляра накладной (верх и низ).
- Между блоками — **пунктирная линия разреза** (смещена на 5 мм от границы фреймов).
- Номер взвешивания **3722**, груз короткий («Кузнецкий 0-300»).

### `baseline_pdf_long.pdf`

- **Две страницы**: первый экземпляр накладной на странице 1, второй — **вверху страницы 2** (режим без двух фреймов на одном листе).
- На второй странице **нет** линии разреза посередине листа (она только в режиме «два блока на одной странице»).
- Номер взвешивания **9999**, длинный перечень слов в грузе (скрипт: `chunk * 3`).

## Регрессия

После правок в `report/pdf_builder.py`:

1. Перегенерировать оба файла командой выше.
2. Визуально сравнить с предыдущей версией (diff PDF или печать).
3. Убедиться: short = 1 стр. + линия; long = 2 стр. без лишней линии на 2-й.
