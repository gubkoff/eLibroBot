# Черновик бизнес-правил (план V3)

Статус: **черновик**, отражает текущий код до рефакторинга.

---

## 1. Сумма (`amount`) — правило из `parser/parser.py` (стр. ~150–156)

**Файл:** `parser/parser.py`

1. Из сообщения парсятся:
   - `price_per_ton` (или `0`, если нет / не распарсилось),
   - `amount` из полей суммы (или `0`),
   - `netto_kg`, `adjusted_netto_kg` (целые кг; при отсутствии корректировки `adjusted_netto_kg` в модели сейчас `0`).

2. Вес для расчёта суммы (кг):
   ```text
   weight_for_amount_kg = adjusted_netto_kg or netto_kg
   ```
   (при ненулевой корректировке берётся она, иначе нетто.)

3. **Пересчёт суммы** (перетирает значение из сообщения), если одновременно:
   - `price_per_ton` **истинно** (не `0`),
   - `weight_for_amount_kg` **истинно** (не `0`).

   Тогда:
   ```text
   amount = (weight_for_amount_kg / 1000) * price_per_ton
   ```
   Округление: `.quantize(Decimal("0.01"))` **без явного режима** (`ROUND_HALF_UP` и т.д. — зафиксировать отдельно в плане, шаг 011).

4. Если **цена = 0** или **вес для суммы = 0** — в `amount` остаётся то, что распарсили из сообщения (или `0`, если суммы в тексте не было).

**Риск (аудит):** число «Сумма» из весовой может **не совпадать** с тем, что попадёт в `WeighingData.amount` и в PDF, **без отдельного поля** «сумма как в сообщении».

## 2. НДС («В том числе НДС») — правило из `report/pdf_builder.py`

**Файл:** `report/pdf_builder.py` (блок итоговой таблицы, ~стр. 327–331).

**База для расчёта:** `total = calculation_result.total`  
(в пайплайне бота сейчас передаётся `CalculationResult(total=data.amount, ...)`, т.е. фактически **та же сумма**, что уже прошла через правила парсера из §1).

**Формула (как в коде):**

```text
nds_amount = (total / 116) * 16
```

Округление: `.quantize(Decimal("0.01"))` **без явного режима** rounding (как и у суммы в §1).

**Интерпретация:** сумма считается **с НДС 16% в составе 116%** (выделение НДС из суммы с налогом):  
\(\text{НДС} = \text{итого} \times 16 / 116\).

**Риск:** логика налога живёт в **модуле верстки PDF**, а не в доменном слое; смена источника `total` или формулы потребует правок PDF и может разъехаться с бухгалтерией, если не зафиксировано договором.
