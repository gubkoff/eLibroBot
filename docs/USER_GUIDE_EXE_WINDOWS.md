# eLibroBot для Windows: как пользоваться exe, настроить .env и включить автозапуск

Инструкция **для пользователя** компьютера с Windows. Устанавливать **Python не нужно** — достаточно файла **`eLibroBot.exe`**, который вам передаст администратор или ИТ-отдел.

---

## 1. Куда положить программу

1. Создайте папку, где бот будет жить постоянно. Например:  
   **`C:\eLibroBot`**
2. Скопируйте в эту папку файл **`eLibroBot.exe`**.

**Важно:** не запускайте exe с флешки «на время» — папка должна быть постоянной, рядом с ней лежит настройка **`.env`**.

---

## 2. Файл настроек `.env`

В **той же папке**, где лежит `eLibroBot.exe`, нужен текстовый файл с именем **точно** **`.env`** (с точкой в начале, без расширения `.txt` в имени, если Windows его не показывает).

### Как создать файл в Блокноте

1. Откройте **Блокнот**.
2. Вставьте строки настроек (ниже — пример).
3. **Файл → Сохранить как…**
4. Папка: та же, где **`eLibroBot.exe`**.
5. Имя файла: **`.env`**
6. Тип файла: **«Все файлы (*.*)»**, кодировка **UTF-8**.
7. Сохраните.

Если Windows не даёт имя `.env`, сохраните как `env.txt`, затем в проводнике переименуйте в `.env` (включите отображение расширений файлов в параметрах папки).

### Что обязательно указать внутри `.env`

Скопируйте шаблон и подставьте **свои** значения (без кавычек вокруг чисел):

```env
BOT_TOKEN=ваш_токен_от_BotFather
TARGET_GROUP_ID=-100xxxxxxxxxx
SOURCE_GROUP_ID=-100xxxxxxxxxx
```

- **`BOT_TOKEN`** — выдаётся в Telegram у **@BotFather** после создания бота.
- **`TARGET_GROUP_ID`** — id **группы, куда бот отправляет PDF** (накладную). Обычно отрицательное число, начинается с `-100…`.
- **`SOURCE_GROUP_ID`** — id **группы (или нескольких групп)**, **из которой** бот читает сообщения о взвешивании.

**Несколько групп-источников** — id через запятую в одной строке:

```env
SOURCE_GROUP_ID=-5101635675,-5248119832
```

Пробелы после запятой допустимы.  
Альтернатива (если так сказали настроить):

```env
SOURCE_GROUP_IDS=-5101635675,-5248119832
```

**`TARGET_GROUP_ID` не должен совпадать** ни с одним id из списка источников.

Строки, начинающиеся с `#`, в примерах выше — это комментарии; в вашем файле их можно не копировать.

---

## 3. Первый запуск вручную

1. Откройте папку с **`eLibroBot.exe`** и **`.env`**.
2. Дважды щёлкните по **`eLibroBot.exe`**.

Должно открыться **чёрное окно** (консоль) — это нормально: там видны сообщения о работе бота. **Не закрывайте** окно, пока бот должен работать.

Если окно сразу закрылось или появилась ошибка:

- проверьте, что **`.env` лежит в той же папке**, что и exe;
- проверьте, что в `.env` нет опечаток и все три переменные заполнены;
- попросите ИТ открыть командную строку в этой папке и запустить `eLibroBot.exe`, чтобы увидеть текст ошибки.

---

## 4. Ярлык на рабочем столе

1. Правой кнопкой по **`eLibroBot.exe`** → **Показать дополнительные параметры** (если есть) → **Создать ярлык**.
2. Перетащите ярлык на **рабочий стол**.
3. (По желанию) Правой кнопкой по ярлыку → **Свойства** → поле **«Рабочая папка»** должно указывать на папку с exe и `.env`, например:  
   **`C:\eLibroBot`**

Дальше бот можно запускать двойным щелчком по ярлыку.

## 5. Автозапуск при включении компьютера (Windows)

Чтобы бот **сам запускался после входа в Windows**, используйте **Планировщик заданий**.

### Шаги

1. Нажмите **Win + R**, введите **`taskschd.msc`**, Enter.
2. Справа выберите **Создать задачу…** (не «простую задачу»).
3. Вкладка **«Общие»**:
   - **Имя:** например `eLibroBot`.
   - Отметьте **«Выполнять только для пользователей, вошедших в систему»** (удобнее для сети и доступа к файлам).
4. Вкладка **«Триггеры»** → **Создать**:
   - **Начать задачу:** **При входе в систему**.
   - При медленном интернете можно указать **Отложить на:** 30 секунд.
   - **ОК**.
5. Вкладка **«Действия»** → **Создать**:
   - **Действие:** запуск программы.
   - **Программа или сценарий:** полный путь к exe, например  
     **`C:\eLibroBot\eLibroBot.exe`**
   - **Рабочая папка:** папка с exe и `.env`, например  
     **`C:\eLibroBot`**
   - **ОК**.
6. Вкладка **«Параметры»** (по желанию):
   - **При сбое выполнения перезапускать через:** 1 минуту, несколько попыток — чтобы бот поднялся после сбоя.
7. **ОК**, при запросе введите пароль Windows, если система попросит.

### Важно

- **Не запускайте** бота одновременно **и из планировщика, и второй раз вручную** — получится два бота и конфликт в Telegram.
- Если бот уже добавлен в автозагрузку планировщиком, **ручной запуск** перед этим не нужен (или отключите задачу на время теста).

### Проверка

В планировщике найдите задачу **eLibroBot** → правой кнопкой → **Выполнить**. Убедитесь, что бот отвечает в Telegram.

---

## 6. Обновление программы

Когда выдадут **новый** `eLibroBot.exe`:

1. Закройте старое окно бота (или отключите задачу в планировщике на минуту).
2. Замените старый **`eLibroBot.exe`** новым в той же папке.
3. Файл **`.env`**, как правило, **не меняют**.
4. Снова запустите бота или включите задачу в планировщике.
