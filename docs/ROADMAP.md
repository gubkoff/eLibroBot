## Этап 2: Парсер сообщений

- [x] **Этап пройден**

**Цель:** из текста сообщения получать список записей `Record`.

**Критерий приёмки:** `parse_message("2025-02-26 100 продукты")` возвращает список из одной записи с полями date, amount=100, category="продукты".

**Подшаги:** см. [TASK_BREAKDOWN.md — Шаг 2](TASK_BREAKDOWN.md#шаг-2-парсер-сообщений) (2.1–2.7).

**Обсуждение / заметки:**

- Реализовано: `parser/models.py` (Record), `parser/parser.py` (parse_message). Форматы даты: YYYY-MM-DD и DD.MM.YYYY. Разделители: пробел, запятая, табуляция. Категория может быть из нескольких слов. Добавлены тесты в `tests/test_parser.py` (для запуска: `pip install pytest`, затем `pytest tests/test_parser.py -v`).

## Этап 3: Калькулятор

- [x] **Этап пройден**

**Цель:** по списку `Record` получить агрегаты для отчёта (total, by_category).

**Критерий приёмки:** `calculate(records)` возвращает структуру с `total` и `by_category`; при пустом списке — без ошибки.

**Подшаги:** см. [TASK_BREAKDOWN.md — Шаг 3](TASK_BREAKDOWN.md#шаг-3-калькулятор) (3.1–3.5).

**Обсуждение / заметки:**

- Реализовано: `report/calculator.py` (CalculationResult, calculate). При пустом списке — total=0, by_category={}. Добавлены тесты в `tests/test_calculator.py`.

## Этап 4: Генерация PDF

- [x] **Этап пройден**

**Цель:** по результатам калькулятора и списку записей сформировать PDF во временный файл.

**Критерий приёмки:** `build_pdf(result, records=...)` возвращает путь к PDF с заголовком, таблицей/сводкой и подписью «Сгенерировано: …».

**Подшаги:** см. [TASK_BREAKDOWN.md — Шаг 4](TASK_BREAKDOWN.md#шаг-4-генерация-pdf) (4.1–4.6).

**Обсуждение / заметки:**

- Реализовано: reportlab в requirements.txt, report/pdf_builder.py (build_pdf). Заголовок eLibroCargoReportBot, таблица записей, сводка по категориям, итог, подпись «Сгенерировано: дата/время». Временный файл через tempfile.NamedTemporaryFile(delete=False, suffix='.pdf').
