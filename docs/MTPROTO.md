# Чтение групп-источников через MTProto (Telethon)

По умолчанию бот получает апдейты через **Bot API** и **не видит** сообщения, отправленные **другими ботами** в группе.

Если в `.env` задать **`TELEGRAM_API_ID`** и **`TELEGRAM_API_HASH`**, приложение переключается на гибридный режим:

- **Чтение** текстов из `SOURCE_GROUP_ID(S)` — через **MTProto** (аккаунт пользователя, библиотека Telethon). Видны сообщения от людей **и от ботов**.
- **Отправка PDF** в `TARGET_GROUP_ID` — по-прежнему через вашего **бота** (`BOT_TOKEN`). Бот должен быть в целевой группе с нужными правами.

Команды **`/start`** и **`/parse`** в Bot API продолжают работать (long polling).

## Настройка

1. Зарегистрируйте приложение на [https://my.telegram.org/apps](https://my.telegram.org/apps) и получите **api_id** (число) и **api_hash** (строка).

2. В `.env` добавьте (вместе с обычными `BOT_TOKEN`, `SOURCE_GROUP_*`, `TARGET_GROUP_ID`):

   ```env
   TELEGRAM_API_ID=12345678
   TELEGRAM_API_HASH=0123456789abcdef0123456789abcdef
   ```

3. **Аккаунт пользователя** (тот, под которым войдёт Telethon) должен быть **участником всех групп-источников** из `SOURCE_GROUP_ID(S)`.

4. Первый запуск без готовой сессии: если в `.env` **нет** `TELEGRAM_PHONE`, в консоли попросят ввести номер (`+7900…`); затем — код из Telegram и при необходимости пароль 2FA. После успешного входа появится файл сессии (по умолчанию `telethon.session` в рабочей папке).

   - Не коммитьте сессию в git.
   - Для сервера без интерактива: один раз залогиньтесь локально, скопируйте **`telethon.session`** (или используйте **`TELEGRAM_SESSION_STRING`** — результат `StringSession.save()`).

5. Опционально:

   - **`TELEGRAM_SESSION_FILE`** — путь к файлу сессии (по умолчанию `telethon.session`).
   - **`TELEGRAM_SESSION_STRING`** — строка сессии вместо файла.
   - **`TELEGRAM_PHONE`** — номер в формате `+79001234567` (удобно для первого входа).
   - **`TELEGRAM_2FA_PASSWORD`** — пароль облака Telegram, если включён 2FA (храните в секрете).
   - **`TELEGRAM_LOGIN_QR=1`** — первый вход **по QR** вместо кода по номеру (см. ниже).

## Код входа не приходит

По умолчанию Telegram шлёт код **в приложение Telegram** на телефоне (уведомление или чат **«Telegram»**).

У сторонних клиентов (в т.ч. Telethon) опция «принудительно SMS» **отключена на стороне Telegram** — параметр `force_sms` в Telethon помечен deprecated и **не работает** (см. [Telethon #4050](https://github.com/LonamiWebs/Telethon/issues/4050)).

### Что сделать

1. Откройте **Telegram на телефоне** → чат **«Telegram»** или **уведомления** с *Login code*.
2. **Настройки → Устройства** — проверьте активные входы.
3. Номер в `.env` в формате **`+7…`** без пробелов.
4. Подождите несколько минут, не спамьте повторными запросами кода.

### Вход по QR (рекомендуется, если код по SMS недоступен)

1. Остановите бота, удалите незавершённый файл **`telethon.session`** (если был).
2. В `.env` укажите **`TELEGRAM_LOGIN_QR=1`** (и при необходимости **`TELEGRAM_2FA_PASSWORD`**).
3. Запустите `python main.py`. В **терминале** выводится **QR-код** (нужен пакет `qrcode`: `pip install qrcode`), плюс в логе остаётся ссылка `tg://login?...`. В Telegram: **Настройки → Устройства → Подключить устройство** — наведите камеру на QR в консоли. Если ссылка на телефоне не открывается, QR в терминале обычно надёжнее.
4. У одной ссылки **короткий срок жизни** (часто ~30–60 секунд). Если не успели подтвердить, приложение **само запросит новый QR** и выведет новую ссылку в лог — повторите, пока не войдёте.
5. После успешного входа сессия сохранится; **`TELEGRAM_LOGIN_QR`** можно снова убрать или оставить — при наличии сессии QR не понадобится.

## Отключение MTProto

Удалите или закомментируйте **`TELEGRAM_API_ID`** и **`TELEGRAM_API_HASH`** — снова будет только Bot API для источников (как раньше).

## Зависимости

```bash
pip install telethon
```

(уже есть в `requirements.txt`.)
