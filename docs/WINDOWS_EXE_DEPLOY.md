# Развёртывание eLibroBot без Python: один `.exe` и ярлык

Целевая машина: **без установленного Python**. На ней достаточно **одного файла `eLibroBot.exe`**, конфигурации **`.env`** и **ярлыка** (и при желании — задачи в планировщике).

> «Один файл» в смысле **приложения**: секреты и настройки по-прежнему лежат в **`.env`** рядом с exe (так безопаснее, чем вшивать токен в exe). Пользователь кладёт в одну папку **два файла** и делает один ярлык на exe.

## 1. Сборка exe (только на ПК с Python, обычно Windows)

1. Клонируйте репозиторий, создайте venv, поставьте зависимости:

   ```bat
   cd C:\path\to\eLibroBot
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   pip install -r requirements-windows-build.txt
   ```

2. Соберите бинарник:

   ```bat
   scripts\windows\build_onefile.bat
   ```

   либо вручную:

   ```bat
   python -m PyInstaller --noconfirm --clean scripts\windows\eLibroBot.spec
   ```

3. Результат: **`dist\eLibroBot.exe`**.

Сборка **должна выполняться на Windows** x64 — получится нативный exe под эту ОС.

## 2. Что положить на целевую машину

Создайте папку, например `C:\apps\eLibroBot\`:

| Файл | Назначение |
|------|------------|
| `eLibroBot.exe` | из `dist\` после сборки — основной бот (всегда с консолью при прямом запуске) |
| `eLibroBotLaunch.exe` | из `dist\` — **лаунчер без окна** (см. ниже) |
| `.env` | скопируйте из `.env.example`, заполните `BOT_TOKEN`, `TARGET_GROUP_ID`, `SOURCE_GROUP_ID` или `SOURCE_GROUP_IDS` |

Опционально: положите **`fonts\DejaVuSans.ttf`** и **`DejaVuSans-Bold.ttf`** в ту же папку (рядом с exe), если на ПК нет подходящих системных шрифтов. На обычном Windows обычно хватает **Arial** из `%WINDIR%\Fonts`.

При старте exe **рабочий каталог** принудительно выставляется на **папку с exe** (см. `scripts/windows/pyi_runtimedir.py`), чтобы файл **`.env`** находился без дополнительных настроек.

### MTProto (Telethon) и первый вход по QR

Если в `.env` заданы `TELEGRAM_API_ID` / `TELEGRAM_API_HASH` и **`TELEGRAM_LOGIN_QR=1`**, а файла сессии ещё нет, при запуске **`eLibroBot.exe`** в **чёрном окне консоли** выводится **QR-код** (и ссылка в логе). Сканируйте его в Telegram: *Настройки → Устройства → Подключить устройство*. После успешного входа рядом с exe появится **`telethon.session`** — дальше QR не нужен, пока сессию не удалят и не отзовут в Telegram.

Сборка **`console=True`** (как в `eLibroBot.spec`) обязательна, иначе окна для QR не будет. Без консоли потребовалось бы отдельное графическое окно.

### Лаунчер `eLibroBotLaunch.exe` (фон после первого входа MTProto)

Лаунчер **без собственного окна** лежит в той же папке, что и `eLibroBot.exe`, и при старте:

1. Читает `.env` в этой папке.
2. Если заданы **`TELEGRAM_API_ID`** и **`TELEGRAM_API_HASH`**, но **нет** сохранённой сессии Telethon (нет файла из `TELEGRAM_SESSION_FILE`, по умолчанию `telethon.session`, и не задана непустая **`TELEGRAM_SESSION_STRING`**) — запускает **`eLibroBot.exe` в новой консоли** (QR, код входа, логи).
3. Иначе — запускает **`eLibroBot.exe` без окна** (бот в фоне, лог в консоли не виден).

Если MTProto в `.env` **не включён**, лаунчер всегда стартует бота **без окна**.

Для отладки и просмотра логов запускайте **`eLibroBot.exe` напрямую** или из `cmd`.

## 3. Ярлыки

**Обычный режим (видно окно с логами):** ПКМ по `eLibroBot.exe` → **Создать ярлык**. В **свойствах ярлыка** поле **«Рабочая папка»** — каталог, где лежат `eLibroBot.exe` и `.env`.

**Тихий запуск после настройки MTProto:** ярлык на **`eLibroBotLaunch.exe`** (та же рабочая папка). При первом входе по QR откроется **отдельное** окно консоли у дочернего `eLibroBot.exe`; после появления `telethon.session` следующие запуски через лаунчер идут **без окна**.

## 4. Автозапуск при загрузке Windows

В **действии** планировщика можно указать либо **`eLibroBot.exe`** (окно/логи), либо **`eLibroBotLaunch.exe`** (без окна, если сессия Telethon уже есть). **Рабочая папка** — каталог с обоими exe и `.env`. Триггер: **При входе в систему** (см. [WINDOWS_AUTOSTART.md](WINDOWS_AUTOSTART.md)).

Не запускайте одновременно **и** exe из планировщика, **и** второй раз вручную — будет два процесса и конфликт long polling.

## 5. Обновление версии

На машине со сборкой: `git pull`, `pip install -r requirements.txt`, снова `build_onefile.bat`, затем замените **`eLibroBot.exe`** и **`eLibroBotLaunch.exe`** на целевой машине (`.env` и `telethon.session` обычно не трогают).

## 6. Ограничения и антивирус

- Размер exe заметный (вшит Python и зависимости).
- Некоторые антивирусы **ложно срабатывают** на PyInstaller — при необходимости добавьте исключение по папке.
- Для отладки на целевой машине временно запустите exe из `cmd`, чтобы увидеть traceback.
